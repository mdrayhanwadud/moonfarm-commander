# 🌙 Moon Farm: Junior Astronaut Mission Trainer

A farm-style game for ages 7 to 12 where kids run a Moon or Mars outpost. Every choice costs something: power, air, food or radiation safety.

**Made for:** NASA Space Apps Challenge 2026, "Build a Junior Astronaut Mission Trainer"

**Play:** https://mdrayhanwadud.github.io/moonfarm-commander/  · 

**Source code:** https://github.com/mdrayhanwadud/moonfarm-commander  · 

**Demo slides:** https://docs.google.com/presentation/d/1AwjqzDxFQcaQnihnwKCFuyTH2RjLQfui/edit?usp=sharing

The Android project (Capacitor) is in the `moonfarm-apk` folder.

## What kids learn
| Real constraint | In the game | Real basis |
|---|---|---|
| Power budgeting | Solar panels make power, machines use it, the battery stores extra. Brownouts stop machines. Moon nights have no sun. Dust lowers panel power. | Lunar night lasts about 14 Earth days. Dust storms blocked rover solar panels on Mars. |
| Life support | The crew breathes every day. The Oxygen maker needs power. Meteorites cause leaks. | The space station makes oxygen from water with electricity. |
| Food production | Greenhouses need power and 2 days to grow. You pick the plants. | Astronauts have grown and eaten lettuce in space. |
| Radiation shielding | Dose only goes up. The Shield cuts it but costs power. Flares add a big dose. | Mars about 0.64 mSv/day (NASA Curiosity). The Moon value is a simplified game value. |
| Communication delay | Help from Earth arrives after 2 days (Moon) or 4 (Mars). | Radio to the Moon takes about 1.3 s one way, to Mars 4 to 24 min. |

## NASA data
- **NASA DONKI** solar flare database: real flares from the last 30 days become the game's flare events, with their real class and date (X needs a level 3 shield, M level 2, C level 1). Works live online. If offline it uses your last saved NASA data, then a small labeled archive.
- **Radiation:** Mars is based on the NASA Curiosity RAD instrument (Hassler et al., Science, 2014). The Moon value is a simplified game value.
- The game says on screen what is live, saved or archived. Full list: [docs/SOURCES.md](docs/SOURCES.md).

## Features
Five themed pages (Power, Air, Food, Radiation, Crew) · a 🎬 Watch section with 5 short animated "See what happens" videos (solar storm, radiation, no power, no food, no air) with captions and optional read-aloud voice · a mini-game on each page · daily missions · name your astronauts · About pages (what it is, in the game, in real space) · NASA science and Quran & Space collectible cards · Explorer mode that shows the formulas (for older siblings and classrooms) · score and mission report · slow unlock of new systems so kids are not overwhelmed (radiation day 3, dust day 4).

## Run it
- Open `index.html` in a browser, or host this folder on GitHub Pages (see [docs/HOSTING-GUIDE.md](docs/HOSTING-GUIDE.md)).
- Live NASA data: get a free key at api.nasa.gov and save it in the game (ℹ️ → 🔑). Use ℹ️ → "Test NASA connection" to check.
- Android: wrap with Capacitor (`npx cap add android`) or install from the browser ("Add to Home Screen").

## Honest limitations
Game numbers are simplified for play (for example 8 power per panel and a 26 mSv game budget). Not medical or engineering advice. Tested by automated bots for balance; child testing results: see `docs/`.
