# Host the game and turn on live NASA data (about 15 minutes)

1. Create a free GitHub account and a new **public** repository named `moon-farm`.
2. Upload everything in this folder (index.html, manifest, sw.js, icons, README.md, LICENSE, docs).
3. Repository **Settings → Pages**: Source = "Deploy from a branch", Branch = `main`, folder `/ (root)`. Save. After about 2 minutes your link is `https://YOURNAME.github.io/moon-farm/`.
4. Get a free NASA key at **api.nasa.gov** (check your email).
5. Open your link on your phone. Tap ℹ️ → 🔑 NASA key → paste → Save.
6. Tap ℹ️ → **Test NASA connection**. You should see ✅. Then open the ☢️ page (after day 3): it should say "Live NASA DONKI".
7. Play online once. The game saves that NASA data, so it still shows real flares if the internet drops during judging.
8. Put the link in README.md and in your submission.

Android app: see the project's HOW-TO-BUILD-APK.txt (Windows) or use "Add to Home Screen" on the link.

## Optional but recommended: Web Filter Classification (5 minutes)
Judges may be blocked from new websites by NASA's web filter. Fill in the FortiGuard Web Filter Classification form for your game link. Category: choose "web-based application" (or "education"). Company Name: write "N/A". Submit. It is not required, and the result is up to FortiGuard.
