HOW TO BUILD THE APK ON WINDOWS (Moon Farm Commander)

1. Extract the ZIP to a short path, e.g. C:\moonfarm-apk
2. Open Android Studio > Tools > SDK Manager.
   - SDK Platforms tab: tick "Android 14.0 (API 34)" and Apply.
   - SDK Tools tab: tick "Android SDK Build-Tools 34", "Android SDK Command-line Tools (latest)", Apply.
3. Open the extracted folder and double-click Build-APK-Windows.bat
   OR open Command Prompt in that folder and run:
       set JAVA_HOME=C:\Program Files\Android\Android Studio\jbr
       gradlew.bat assembleDebug
   (If you use the manual command, create a file named local.properties containing:
       sdk.dir=C:/Users/YOUR_NAME/AppData/Local/Android/Sdk )
4. The first build needs internet to download Gradle and libraries (5-15 min).

After success the APK is at:
   app\build\outputs\apk\debug\app-debug.apk
and a copy named Moon-Farm-Commander.apk is placed next to the .bat file.
Transfer it to your Android phone and install it (allow "Install unknown apps").

You can also still open this folder directly in Android Studio (File > Open) and press Run.
To edit the game: app\src\main\assets\public\index.html (replace DEMO_KEY with your NASA key from api.nasa.gov).

MUSIC
The game plays an original generated space-organ soundtrack. To use your own ROYALTY-FREE track instead
(do not use copyrighted songs), name it music.mp3 and put it in app\src\main\assets\public\ , then rebuild.
